# Санаторий-профилакторий

Архитектурный чертёж с планами четырёх этажей.

## Готовые файлы

- [Исправленный DXF](drawings/Sanatoriy_edited.dxf) — основной редактируемый чертёж, формат AutoCAD 2018.
- [PDF для просмотра](exports/Sanatoriy_review.pdf) — четыре листа.
- [Архив готового DXF](exports/Sanatoriy_edited.zip) — чертёж, таблица помещений и примечания.
- [Экспликация помещений CSV](tables/room_schedule.csv) — UTF-8, разделитель `;`.

## Исходные файлы

- [Исходный DWG](sources/Original.dwg).
- [Исходный DXF в ZIP](sources/Original_DXF.zip).

Исходники сохранены без изменений. Файлы блокировки DWL/DWL2 для работы с чертежом не нужны.

## Выполненные изменения

На этажах 2–4 убраны внутренние подписи площадей, размеров труб, стояков и их выноски по образцу первого этажа. Внешние размерные цепочки и оси сохранены. Номера помещений добавлены после названий; справа внизу каждого листа размещена экспликация.

| Этаж | Номера помещений | Количество |
| --- | --- | --- |
| 1 | 100–147 | 48 |
| 2 | 200–244 | 45 |
| 3 | 300–366 | 67 |
| 4 | 400–455 | 56 |

Всего 216 помещений. Помещение №243 в исходнике не имело названия и обозначено «Помещение». Открытая лестница в вестибюле и неопределённые шахты отдельно не нумеровались. Исправлены три повреждённые подписи санузлов и убраны два точных дубля подписей лоджий.

## Работа с проектом

Откройте `drawings/Sanatoriy_edited.dxf` в AutoCAD или другом совместимом CAD-редакторе. При необходимости сохраните его в DWG средствами редактора. Таблицы легенд находятся на слое «Экспликация помещений». Для просмотра без CAD используйте PDF.

## Проверка

DXF проверен с помощью ezdxf 1.4.4: аудит без ошибок. Все 168 исходных объектов DIMENSION сохранены без изменений. Нумерация на планах, в легендах и CSV совпадает; пропусков и повторов нет.
